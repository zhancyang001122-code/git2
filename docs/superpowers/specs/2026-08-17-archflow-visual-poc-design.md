# ArchFlow 视觉 POC 设计说明

## 目标

为面试演示制作一份无需后端即可运行的单文件 HTML POC。它不改变 PRD 已确定的六个核心功能，只验证视觉语言、页面层级、输入引导、生成反馈和资产沉淀体验。

## 演示重点

1. 面试官在 30 秒内理解 ArchFlow 是面向建筑设计企业与设计团队的 AI 提效工作台。
2. 首页同时呈现品牌气质、核心功能入口和一条清晰的演示主线。
3. 功能页使用“任务对话框 + 结构化快捷项 + 右侧建议输入”降低专业输入门槛。
4. “我的”页面使用项目包/文件包卡片组织灵感、方案、图纸、模型、渲染和汇报资产。
5. 所有生成均为本地假数据，但保留清晰的 `generateWithApi` 接口边界，后续可替换为真实生图 API。

## 共用信息架构

- 左侧主导航：首页、AI 方案灵感、AI 方案设计、AI 图纸美化、AI 建模、AI 渲染、AI 汇报、我的。
- 顶部状态区：当前项目、演示模式、API 状态占位、主题切换。
- 首页：品牌主视觉、最近项目、六项能力、推荐演示路径。
- 核心功能页：任务标题、对话式输入区、附件入口、建议输入侧栏、生成状态、按 PRD 区分的专业结果区。
- 我的：项目包总览、类型筛选、搜索、更新时间、文件数量、封面叠层和快捷动作。

## 三套视觉方向

### A. Daylight Editorial（推荐）

- 米白背景、近黑正文、日光橙强调色。
- 超大标题、编辑式非对称网格、大幅建筑视觉。
- 小圆角、窄边框、全大写 Mono 标签，最接近 Daylight 的品牌语言。
- 优势：辨识度高、作品集感强、面试第一眼有记忆点。

### B. Blueprint Atelier

- 冷白纸张、深海军蓝、明亮青蓝强调色。
- 建筑网格、坐标和图纸标注语言，卡片更理性克制。
- 优势：建筑专业属性最强，容易解释信息架构和设计系统。

### C. Night Studio

- 深炭背景、暖橙高光、半透明面板和电影感建筑画面。
- 强调 AI 生成过程、进度与结果对比。
- 优势：科技感和演示氛围最强，适合投屏，但长时间阅读不如浅色方案。

## 输入交互

- 主输入采用可扩展多行对话框，支持自然语言描述任务。
- 输入上方提供项目类型、面积、场地、风格等快捷标签；点击后写入对话框。
- 右侧常驻“怎样描述效果最好”，按“必填、建议、可选”展示字段，并提供一键填充示例。
- 上传型功能显示拖拽区；本地 POC 只显示文件名和预览状态，不上传任何文件。
- 提交后依次展示理解需求、组织提示词、生成结果三个状态，随后显示假数据结果。
- 结果明确标记为“演示样本”，提供重新生成和保存到“我的”的按钮。

## 差异化输出

- AI 方案灵感：多个设计方向、设计逻辑、空间策略、视觉关键词、真实案例链接、匹配理由与 Mood Board。
- AI 方案设计：A/B/C 设计概念、空间策略、功能组织、体量分析、专业比选和最终方案选择。
- AI 图纸美化：原图与美化后图的可拖动对照、表达增强项和不可修改边界。
- AI 建模：可旋转/缩放的基础模型预览，以及 `.skp`、`.3dm` 下载接口占位。
- AI 渲染：1–2 张大图结果，支持大图查看、下载和重新生成。
- AI 汇报：PPT 页序与单页预览、自动叙事结构、A3 版式图和导出接口占位。

## 资产包 UI

- 每个项目包使用 2–3 张缩略图叠放形成“文件包”封面，与参考图的悬浮卡片层次一致。
- 卡片展示项目名称、资产类型、文件数量、最近更新时间和生成来源。
- 支持类型筛选、搜索和打开资产详情。
- 保存操作会在本地页面状态中新增资产包，证明“生成 → 保存 → 我的”闭环。
- 每个资产包提供删除入口；删除前二次确认，删除后文件数、项目包数、当日保存数和容量估算联动更新，并提供空资产状态。

## API 接口边界

```js
async function generateWithApi({ feature, prompt, files, options }) {
  // POC 返回本地演示数据。
  // 后续在此接入真实文本/生图/建模/导出 API。
}
```

页面组件不直接调用第三方服务，后续仅替换该适配器即可。

## 响应式与可访问性

- 桌面端采用 240px 左侧导航、弹性内容区和 300px 建议侧栏。
- 平板折叠建议侧栏为抽屉；移动端导航改为顶部菜单，表单和结果单列显示。
- 保留可见焦点、语义标签、键盘操作、足够对比度，并尊重 `prefers-reduced-motion`。

## 本轮不实现

- 真实登录、真实数据库、真实生图/建模/PPT 导出。
- CAD/BIM 解析和施工级精度能力。
- 多人协作、正式审批和企业知识库的真实后端能力；POC 仅展示企业工作区、项目上下文和资产来源等产品线索。
