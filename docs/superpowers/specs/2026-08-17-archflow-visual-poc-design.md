# ArchFlow React Blueprint POC 设计说明

## 目标

为面试官提供一套可在 3 分钟内讲清楚产品定位、专业判断与工程边界的企业建筑设计 AI 工作台。前端使用 React + Vite，不依赖后端即可完整演示；同时预留可真实调用的用户 API 适配层。

## 视觉方向

采用 Blueprint 作为唯一主视觉：

- 冰蓝与冷白背景，深海军蓝作为信息和交互主色，亮青蓝作为状态强调；
- 大面积低对比工作台与高对比核心操作并存；
- 侧边导航、顶部栏和生成面板使用磨砂玻璃，不降低正文可读性；
- 通过悬浮文件层、图纸网格、微透视工作台和轻阴影呼应参考图；
- 不依赖照片素材，建筑、图纸、模型和渲染预览均用可控的 CSS 图形表达；
- 所有主按钮 Hover 时执行深蓝 / 青蓝或白色 / 深蓝反色，提供明确点击反馈。

## 信息架构

- 工作台：首页主视觉、六个 AI 能力入口、本周概况、会话级项目备忘录和演示路径；
- AI 方案灵感：设计方向、空间策略、关键词、相关案例；
- AI 方案设计：A / B / C 概念方案、体量和专业比选；
- AI 图纸美化：图纸前后拖动对比和增强指标；
- AI 建模：模型旋转 / 缩放、质量报告和格式下载；
- AI 渲染：单张效果图、原图 / 生成图滑杆对比、大图查看和下载；
- AI 汇报：页面序列、单页预览、演讲结构和导出；
- 我的资产：项目文件夹、搜索、筛选、详情、保存和删除。

## 输入规则

每个功能页都使用统一输入骨架，但内容根据功能变化：

1. 自然语言任务描述；
2. 三个模块专属快捷补充项；
3. 项目附件入口；
4. “必填 / 建议 / 可选”三层专业提示；
5. 推荐描述结构；
6. 加载、完成、错误三种反馈状态。

附件可通过选择文件或在文本框内使用 `Ctrl + V` 粘贴图片加入。附件预览显示在输入区上方，“选择文件”按钮显示数量徽标，并支持单项移除。文件只存在当前模块内存；启用真实 API 后，图片会发送给用户配置的第三方模型服务。

## 差异化输出

- 方案灵感输出三种有命名、有逻辑差异的设计方向，并附共同空间策略与可点击案例；
- 方案设计输出三套体量逻辑与指标表，必须先选择一套方案再保存；
- 图纸美化使用真实可拖动对比，而不是静态结果卡片；
- 建模提供可旋转、缩放和重置的空间对象；
- 渲染强制上传参考图，只提供一张生成图，并以可拖动滑杆对照原图；
- 汇报提供页面轨道、当前页预览和前后翻页交互。

## 资产文件夹

- 资产卡片保持明确的磨砂玻璃文件夹外形，只包含三张整齐文件纸、文件夹标签和文件数量；
- 每个资产显示来源模块、更新时间、文件数量和类型；
- 支持搜索、类型筛选和动态统计；
- 资产可打开详情并下载演示包；
- 删除必须经过二次确认，确认后列表与统计联动更新。

## 本周概况与备忘录

- 工作台主卡片用于呈现本周设计进度、生成数量、资产复用与活跃趋势；
- 卡片底部输入用于创建项目备忘录，创建后即时显示在上方；
- 概况模式最多展示两条最近备忘录，第 3 条起显示“更多”入口；
- 点击“更多”进入完整备忘录详情，并可返回本周概况；
- 点击概况卡片或完整列表中的任意备忘录，打开独立详情弹窗并支持编辑保存；
- 备忘录与当前 POC 资产一样只存在页面会话内，不承诺刷新后留存。

## 脱敏身份与 API

- 左下角身份统一显示为“方案一组”，并标记“访客演示 · 信息脱敏”；
- 身份入口与 API 状态入口分别打开账户说明和模型密钥配置弹窗，为后续真实登录留出独立边界；
- 账户弹窗明确说明不展示真实姓名、邮箱和企业名称；
- ArchFlow 预设语言大模型与生图大模型的 Base URL、模型名和输出规格，用户可填写一把语言模型 Key 与一至两把生图模型 Key；
- 默认预设为百炼 `qwen-plus` 与第三方 `gpt-image-2`，允许配置第二套官方或第三方生图服务，但不允许把 API Key 写入构建变量；
- 配置只保存在当前标签页的 `sessionStorage`；
- AI 渲染页在生成按钮左侧提供生图模式选择；仅连接一个生图 API 时锁定，连接两个时可切换并按所选服务路由；
- 启用后，方案灵感与方案设计请求 `/chat/completions`，AI 渲染请求 `/images/edits`；失败时展示明确错误，不回退伪成功；
- GitHub Pages 浏览器直连仅供“访问者自带 Key”的演示，生产环境或免填 Key 模式必须使用服务端代理。

## 响应式与可访问性

- 桌面端使用固定玻璃侧栏、悬浮顶部栏和弹性内容区；
- 920px 以下侧栏改为抽屉；650px 以下所有工作流与结果改为单列；
- 语义化使用 `nav`、`main`、`section`、`button`、`label` 和 `dialog`；
- 键盘焦点可见，主要交互具有明确的可访问名称；
- 遵守 `prefers-reduced-motion`，加载动画仅用于任务反馈；
- 玻璃效果不受支持时回退为高不透明度背景。

## 当前边界

已实现真实前端交互，以及方案灵感、方案设计、AI 渲染三类真实 API 适配。CAD / BIM 解析、模型生成、对象存储、数据库、权限、跨设备资产和真实文件导出不在本轮前端 POC 范围内，工程演进见 `docs/TECHNICAL_ARCHITECTURE.md`。
